# Nike Sales Data Analytics – End-to-End Business Case Study

## 1. Project Overview

This project focuses on analysing Nike sales data to understand business performance, profitability, regional sales trends and product performance.

The objective is to transform raw sales data into meaningful business insights using Excel, Python, SQL and Power BI.

## 2. Problem Statement

Businesses need to understand which products and regions contribute most to revenue and profit. This project analyses Nike sales data to identify performance trends, evaluate profitability and support data-driven business decisions.

## 3. Dataset Information

The project uses a Nike sales dataset containing sales and business-related information, including product details, regions, sales and profit.

The dataset was cleaned and prepared before performing further analysis.

## 4. Data Cleaning – Excel

Excel was used to prepare the dataset for analysis.

The cleaning stage focused on preparing a consistent and usable dataset for further analysis.

## 5. Exploratory Data Analysis – Python

Python and its data analysis libraries were used to explore the cleaned dataset.

Key activities:

* Data exploration and inspection.
* Analysis of sales and profit.
* Regional performance analysis.
* Product-related analysis.
* Visual representation of findings.

## 6. SQL Analysis – MySQL

MySQL was used to perform structured queries on the cleaned Nike sales dataset.

One of the key findings was the regional profit distribution:

| Region    | Total Profit |
| --------- | -----------: |
| Bengaluru |   621,948.74 |
| Kolkata   |   602,856.74 |
| Delhi     |   587,148.93 |
| Mumbai    |   569,568.34 |
| Pune      |   533,414.00 |
| Hyderabad |   525,094.60 |

Bengaluru recorded the highest profit among these six regions, while Hyderabad recorded the lowest.

## 7. Power BI Dashboard

An interactive Power BI dashboard titled **Business Performance and Sales Overview** was developed to present business performance through visualisations, KPI cards and interactive filters.

The dashboard helps users explore sales performance and identify important business trends.

## 8. Key Business Insights

* Bengaluru recorded the highest regional profit among the six regions analysed.
* Hyderabad recorded the lowest regional profit among the six regions analysed.
* Regional profitability varies, highlighting opportunities for further investigation.
* Combining Excel, Python, SQL and Power BI makes it easier to transform raw data into actionable business information.

## 9. Tools and Technologies

* Microsoft Excel – Data Cleaning
* Python – Exploratory Data Analysis
* Pandas and NumPy – Data Manipulation
* MySQL – SQL Analysis
* Power BI – Interactive Dashboard
* GitHub – Project Documentation and Version Control

## 10. Conclusion

This project demonstrates an end-to-end data analytics workflow, starting from data cleaning and exploration to SQL analysis and interactive dashboard development.

It provided practical experience in analysing business data, identifying patterns and presenting findings to support informed decision-making.

## Business Recommendations

Based on the analysis, the following recommendations can help improve business performance:

1. **Regional Performance:** Investigate the factors contributing to lower profitability in Hyderabad and Pune to identify improvement opportunities.

2. **Focus on High-Performing Regions:** Study successful sales strategies in Bengaluru and Kolkata and explore opportunities to replicate them in other regions.

3. **Product Performance:** Identify high-performing and low-performing product categories to improve inventory planning and sales strategies.

4. **Data-Driven Decisions:** Regularly monitor sales, revenue and profit through interactive dashboards to support better business decisions.
